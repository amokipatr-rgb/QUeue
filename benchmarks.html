How to Read This Report

Served — completed tokens assigned to the officer in range. Avg Wait — mean minutes from token request to service start, across valid waits only (a wait is valid when service actually started; weighted by wait count, not a plain average of averages). Target — each token's own service estimate (default 15 min); the wait chart draws the 15-minute reference line because per-service targets vary. Breaches — individual waits exceeding that token's target. An average below target can still hide breaches — the count and red dots show them. Compliance — valid waits within target ÷ valid waits. On Duty — session hours overlapping the range. vs Prev — same-length prior period; labeled per metric (e.g. Avg wait −12%). Zero served + duty hours is flagged amber (needs investigation); zero served + zero duty is greyed as off duty, not poor performance. Rankings sort by any column — volume alone never decides.
